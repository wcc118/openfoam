# Executed native wing feedback drivers

These primary-owned historical sources preserve fixed PC paths and the pinned
existing runtime; they are experiment provenance, not general launch APIs.
`run_pc.py` consumes a source archive containing the main modal/transfer scripts,
`native_modal_participant.py` and `prepare_assets.py`, and creates exclusive case
folders for explicit, half-step and implicit controls. Existing cases are not
modified. All three solver commands exited0. Repeated source paths in manifests
refer to archived input snapshots, not imports from mutable sibling worktrees.

`analyze_pc.py` checks native load sums and fits the saved CFD wall to H*q; it uses
the last native record at each accepted time to exclude rejected implicit trials.
`analyze_wrapper_pc.py` supplies the already-pinned Python/NumPy runtime after the
WSL host Python lacked NumPy (no solver retry or host dependency installation).
`collect_pc.py` retains105 files; archive hash is in the milestone report.
`plot.py` consumes the combined assessment JSON and emits the static PNG.

Upstream preCICE/OpenFOAM-adapter code remains in the existing pinned runtime with
its own licenses; these drivers do not assign a license to owner code. Full model,
units, initial-condition and approximation limits are in the contract and report.
