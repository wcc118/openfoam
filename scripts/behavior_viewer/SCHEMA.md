# Behavior viewer schema v1 (primary-owned scientific contract)

`data.py` and `../build_behavior_viewer.py` are frontier-owned. Do not change numerical interpretation or these files without escalating. The builder embeds compact JSON into a single offline HTML file. Template must have exactly one `__BEHAVIOR_DATA__` and one `__BEHAVIOR_SCRIPT__`, in separate data/script tags. Data tag suggested id `behavior-data` with type application/json. JS reads its textContent. Never fetch data or CDN assets. No dependencies.

Top-level: schema_version, title, native_sha256, contract, conventions, limits (strings), sources (hash map), source_issue URL, geometry, speeds.

geometry: points_m[N][3], basis_xyz_per_q[20][N][3], triangles[T][3], note. Rendering point = points_m + sum over modes(basis * q). This full symmetric shell surface is sampled only for display, not a CFD mesh. Camera may rotate it; no changes to physical coordinates/data. Static magnification changes only displayed modal displacement, not geometry dimensions or metric readouts. Geometry at zero q is undeformed. Root at y=0. Native basis already normalized and mirrored: do not normalize again.

speeds: exactly20 rows60..250 knots, each speed_kn, speed_m_s, mach, uvlm object, cfd array (possibly empty), transient (object or null).

uvlm: q[20], alpha_deg, lift_lbf, tip_in, twist_deg, span_profile[49][3] = positive half-span position inches / vertical displacement inches / chord rotation degrees. tip_in is mean native tip node vertical displacement, not absolute z. twist positive TE-up relative to undeformed chord. elapsed_s is equilibrium-only timing (not a complete sweep/pole/dynamics runtime). timing_scope, status, pole_status, weakest_growth_per_s, weakest_frequency_hz, bending_growth_per_s, bending_frequency_hz.

cfd item: id, label, q_pose[20], alpha_deg, lift_lbf, tip_in, twist_deg, span_profile, lift_error_pct (relative to target30lbf), balance_correction_in (residual structural balance diagnostic; NEVER apply it as a deformation), stationary bool, loaded_gate bool, status[] explanations, solver, elapsed_s (nullable), timing_scope, iterations, history[[iteration,lift_lbf]], history_axis, matched_uvlm_inputs bool, alpha_difference_deg, q_max_difference, lift_difference_lbf, comparison_label, shape_label, source.
- q_pose is the HELD candidate/reference shape during a fixed-pose CFD run; not a CFD-solved deformation or transient response. Render only that held pose; show shape_label.
- At60kn, inputs differ from UVLM; never label lift_difference as matched-method error/accuracy.150/250kn matches target pose and angle, but CFD load balance fails. Method differences do not tell which is accurate. Missing speeds have empty cfd arrays; never fill zeros or interpolate CFD.
- loaded_gate pass is not qualification: global settings sensitivity remains unresolved; CFD stability is unassessed. Historical baseline has no history included. All unqualified cases visible/selectable by default.

transient only at60,150,250: label, time_s[K] (every recorded sample), q_delta[K][20] perturbations about row.uvlm.q, tip_delta_in[K], twist_delta_deg[K], initial_grid_displacement_in, scope, seconds, sample_dt_s.
- This is one actual first-bending release from a20-mode UVLM surrogate, not arbitrary oscillation and not CFD. Shape = undeformed + displayed equilibrium displacement + displayed transient displacement. If playback uses sample interpolation, label it display interpolation, not a new solve. Keep playback speed (physical seconds per wall second) and perturbation exaggeration separate and visibly labeled. Default deformation and perturbation scale1. End at recorded end, no invented continuation. No animation when no history; changing selected speed isn't a dynamic simulation. Charts use physical time for transient, iteration for CFD.

UI acceptance: owner wants understanding of wing behavior first, not a log table. Large rotatable wing, visible unloaded reference and selected method legend, speed slider/select, clear measured metrics, trends over all speeds, selected CFD cases and method comparison conditions, stationarity/load-balance/model-evidence distinctions, recorded-release controls, and plain-language interpretations. At least reset camera and a view from span/front plus isometric. Imperial units visible on metrics/charts, SI source conventions accessible. Pressure colors/flow lines are not available; do not invent them. Runtime readouts need task scope; do not compute a speedup ratio from unlike tasks. Experimental accuracy unknown, no measured correlation supplied. Numerical disagreement is useful evidence and stays visible.

Use HTML textContent or properly escaped content for labels; no raw data innerHTML. Native data is27MB; avoid recomputing all-time geometry each draw. Draw only selected q vector plus a current recorded transient frame. Downsample plot rendering by pixel envelopes if needed, but don't change recorded source samples or derive stability from plotted samples.
