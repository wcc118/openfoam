# Offline true 3D viewer contract (issue 5)

Primary-selected renderer: vtk.js 35.5.1, vendored UMD global `vtk`. Source npm vtk.js@35.5.1; package integrity sha512-alopSK4t9/+bnNYlP3KHYiDmXInLyl7OevV4BGmTlT7a5jGUtTJxoibovAO9nUxDOex0/hNkx6Q6nlxo1Ez4aw==. Vendor licenses are adjacent; do not replace or change dependencies.

Input JSON schema version 1, kind `native-flow-3d`, one independently solved case. All arrays flat, finite numbers. `metadata` contains title, alpha_deg, steady_iteration, provenance (object), limitations (nonempty string array). `wing`: points [x,y,z,...], polys VTK cell array [3,i,j,k,3,...]. `paths`: points, lines VTK cell array [n,i0,...,n,...] (n>=2), speed per point m/s. `vortex`: points, polys triangles, speed per CELL m/s. `volume`: dimensions [nx,ny,nz] >=2, origin [x,y,z] m, spacing [dx,dy,dz]>0 m, speed array nx*ny*nz with x fastest. -1 sentinel means absent native sample and MUST be transparent; all others >=0. Scalar display range speed 0..45 m/s. No angle/time control because only one saved case. No fetch/network requests; embed vendor and JSON in one HTML.

Use vtkGenericRenderWindow with container; vtkPolyData points and cells typed arrays; vtkDataArray Speed; paths point scalars and vortex cell scalars; mapper lookup table vtkColorTransferFunction (0 blue,15 cyan,30 yellow,45 red), fixed range. vtkTubeFilter optional for paths (radius .0012 m, 6 sides), not required if brittle. Opaque wing actor; scalar actors independently toggled, vortex opacity range .1..1. vtkImageData volume with speed scalars; vtkVolumeMapper, vtkVolume, color and opacity functions. Nearest-neighbor volume interpolation deliberately avoids bleeding -1 mask into air; transfer -1=0,0=0,10=.01,30=.025,45=.06 (adjust scale via volume opacity slider). ScalarOpacityUnitDistance .01m; sampleDistance .005m; shading off. Volume default off. Main default paths+surface, button to show volume. Geometry stays in SI.

Camera preset full wing+wake and right tip, orbit/pan/zoom via vtk interactor. First default full scene angled from downstream/+y/up, viewUp z. Reset reproducible. Legend, title, diagnostic label and visible limitations. Expose window.flow3dTest={renderer,renderWindow,actors:{wing,paths,vortex,volume},data} for browser verification, no mutation used to fabricate data. Show readable error if WebGL unavailable. Text from data uses textContent. Builder JSON escapes < > & U+2028/U+2029 and vendor/template script boundaries safely. Reject invalid shape, cell counts/index bounds/nonintegers, NaN/Inf, wrong scalar lengths/sentinels and empty geometry. Do not silently repair invalid arrays.

Primary implementation refinements: tube radius .0012m (illustrative), explicit
TubeFilter input scalar selection, and optional opacity suppression of29–31m/s.
Suppression defaults on: knots(-1,0),(0,0),(10,.04),(25,.025),(29,0),(31,0),(35,.04),(45,.08).
Disable it for the original full-volume opacity transfer. Volume opacity slider
scales these knots; it does not alter samples. Overview uses1.35 camera zoom.
