Assumptions and limitations

    Tip displacement and twist histories

    Drag either view to rotate both; shift-drag to pan, scroll to zoom. Faint wireframe is the undeformed mesh. Perturbation mode draws q minus the case reference on this same mesh; it does not draw the loaded reference shape.

    Axes: x downstream, y spanwise, z up. Tip nodes defined by max y. Twist computed as θ_y = Σ((z−z_c)·u_x − (x−x_c)·u_z) / Σ((z−z_c)²+(x−x_c)²) in degrees. Physical values independent of visual magnification.
